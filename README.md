## 🇺🇸 English

YouTube Enhancer is a userscript for **Violentmonkey** that improves YouTube's layout, visual clarity, and usability through a modern bilingual settings panel.

### ✨ Main Features

1. **🎨 Grid Layout Control**
   - Choose how many videos appear per row (**3 to 8**).
   - Includes responsive behavior for smaller screens.

2. **🚫 Shorts Removal**
   - Removes Shorts shelves, menu entries, and Shorts-style listings.

3. **🧹 Remove (Most Relevant)**
   - Removes the **“Most relevant”** shelf from the Subscriptions page when enabled.
   - The option is disabled by default and can be changed at any time in Settings.

4. **⏰ Floating Clock (Fullscreen)**
   - Displays the time over the video during fullscreen playback.
   - Automatically hides while player menus, including the resolution menu, are open.
   - Supports customizable text color, background color, background opacity, size, margin, and border radius.
   - The default background is `#000000`, with default opacity `0.3`.

5. **🧼 RTX Visual Mode (No Blur/Translucency)**
   - Removes blur and `backdrop-filter` effects from the YouTube interface.
   - Replaces translucent backgrounds with transparent or solid alternatives as appropriate.
   - Keeps timeline hover preview thumbnails, including chapter previews, visible.

6. **🌐 Bilingual Interface**
   - Provides complete Portuguese and English labels and descriptions in the settings panel.

### ⚙️ Settings Panel

No code editing is required:

1. Open the Violentmonkey script menu.
2. Click **“⚙️ Settings”**.
3. Configure the features and clock appearance.
4. Use **Apply** for immediate changes. Changing the interface language offers **Apply and Reload**.

You can also open Settings with <kbd>Alt</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd>.

### 📥 Installation

1. Install **Violentmonkey** in your browser.
2. Install the script using the direct link in the badge above, or paste the source manually.
3. Open `www.youtube.com`.

### 🛠️ Technologies

- JavaScript (ES6+)
- GM API (`GM_getValue`, `GM_setValue`, `GM_registerMenuCommand`)
- Dynamic CSS injection
- DOM observers and SPA navigation handling

## 🇧🇷 Português

O YouTube Enhancer é um userscript para **Violentmonkey** que melhora o layout, a limpeza visual e a usabilidade do YouTube por meio de um painel moderno e bilíngue de configurações.

### ✨ Funcionalidades Principais

1. **🎨 Controle de Layout Grid**
   - Permite escolher quantos vídeos aparecem por linha (**3 a 8**).
   - Inclui comportamento responsivo para telas menores.

2. **🚫 Remoção de Shorts**
   - Remove prateleiras, entradas de menu e listagens do tipo Shorts.

3. **🧹 Remover (Mais Relevantes)**
   - Remove a prateleira **“Mais relevantes”** da página de inscrições quando a opção está ativa.
   - A opção vem desativada por padrão e pode ser alterada a qualquer momento nas configurações.

4. **⏰ Relógio Flutuante (Tela Cheia)**
   - Exibe a hora sobre o vídeo durante a reprodução em tela cheia.
   - Oculta-se automaticamente enquanto menus do player, incluindo o menu de resoluções, estiverem abertos.
   - Permite ajustar cor do texto, cor e opacidade do fundo, tamanho, margem e arredondamento.
   - O fundo padrão é `#000000`, com opacidade padrão `0,3`.

5. **🧼 Modo RTX (Sem Blur/Translucidez)**
   - Remove efeitos de blur e `backdrop-filter` da interface do YouTube.
   - Substitui fundos translúcidos por alternativas transparentes ou sólidas conforme necessário.
   - Mantém visíveis as miniaturas de prévia da timeline, incluindo prévias de capítulos.

6. **🌐 Interface Bilíngue**
   - Oferece rótulos e descrições completos em português e inglês no painel de configurações.

### ⚙️ Painel de Configurações

Não é necessário editar o código:

1. Abra o menu do script no Violentmonkey.
2. Clique em **“⚙️ Configurações”**.
3. Ajuste as funcionalidades e a aparência do relógio.
4. Use **Aplicar** para mudanças imediatas. Ao alterar o idioma da interface, será oferecida a opção **Aplicar e Recarregar**.

Também é possível abrir as configurações com <kbd>Alt</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd>.

### 📥 Instalação

1. Instale a extensão **Violentmonkey** no navegador.
2. Instale o script pelo link direto do badge acima ou cole o código-fonte manualmente.
3. Acesse `www.youtube.com`.

- Injeção dinâmica de CSS
