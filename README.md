## 🇺🇸 English

YouTube Enhancer **2.3.2** is a userscript for **Violentmonkey** that improves YouTube's layout, visual clarity, and usability through a modern bilingual settings panel.

### ✨ Main features

1. **🎨 Grid Layout Control**
   - Choose how many videos appear per row (**3 to 8**).
   - Uses responsive behavior on smaller screens.

2. **🚫 Shorts Removal**
   - Removes Shorts shelves, menu entries, and Shorts-style listings.

3. **🧹 Remove (Most relevant)**
   - Removes the **“Most relevant”** shelf from the Subscriptions page when enabled.
   - The option is disabled by default and can be changed without reloading.

4. **⏰ Floating Clock (Fullscreen)**
   - Displays the time over fullscreen playback without covering YouTube's settings and resolution menus.
   - Supports adjustable text color, background color, opacity, font size, margin, and border radius.
   - The default background is `#000000`, with background opacity set to `0.3`; both remain customizable.

5. **🧼 RTX Visual Mode (No Blur/Translucency)**
   - Removes blur and backdrop-filter effects from YouTube's interface.
   - Keeps menus readable and preserves timeline/chapter preview thumbnails.

6. **🌐 Bilingual Interface**
   - Complete settings-panel support for English and Brazilian Portuguese.

### ⚙️ Settings panel

1. Open the Violentmonkey script menu.
2. Click **“⚙️ Settings”**.
3. Configure the features and clock appearance.
4. Use **Apply** for immediate changes. A language change uses **Apply and Reload**.

Keyboard shortcut: `Alt` + `Shift` + `S`.

### 📥 Installation

1. Install **Violentmonkey** in your browser.
2. Install the script using the direct link in the badge above, or paste the source manually.
3. Open `www.youtube.com`.

### 🛠️ Technologies

- JavaScript (ES6+)
- GM API (`GM_getValue`, `GM_setValue`, `GM_registerMenuCommand`)
- Dynamic CSS injection
- DOM caching and SPA navigation handling

## 🇧🇷 Português

O YouTube Enhancer **2.3.2** é um userscript para **Violentmonkey** que melhora o layout, a clareza visual e a usabilidade do YouTube por meio de um painel moderno e bilíngue de configurações.

### ✨ Funcionalidades principais

1. **🎨 Controle de Layout Grid**
   - Permite escolher quantos vídeos aparecem por linha (**3 a 8**).
   - Usa comportamento responsivo em telas menores.

2. **🚫 Remoção de Shorts**
   - Remove prateleiras, entradas de menu e listagens do tipo Shorts.

3. **🧹 Remover (Mais Relevantes)**
   - Remove a seção **“Mais relevantes”** da página de inscrições quando a opção está ativa.
   - A opção vem desativada por padrão e pode ser alterada sem recarregar a página.

4. **⏰ Relógio Flutuante (Tela Cheia)**
   - Exibe a hora sobre o vídeo em tela cheia sem cobrir os menus de configurações e resolução do YouTube.
   - Permite ajustar cor do texto, cor do fundo, opacidade, tamanho da fonte, margem e arredondamento.
   - A cor de fundo padrão é `#000000`, com opacidade de fundo `0,3`; ambas continuam personalizáveis.

5. **🧼 Modo RTX (Sem Blur/Translucidez)**
   - Remove efeitos de blur e backdrop-filter da interface do YouTube.
   - Mantém os menus legíveis e preserva as miniaturas de prévia da timeline e dos capítulos.

6. **🌐 Interface Bilíngue**
   - Suporte completo do painel de configurações para português brasileiro e inglês.

### ⚙️ Painel de configurações

1. Abra o menu do script no Violentmonkey.
2. Clique em **“⚙️ Configurações”**.
3. Ajuste as funcionalidades e a aparência do relógio.
4. Use **Aplicar** para alterações imediatas. A troca de idioma usa **Aplicar e Recarregar**.

Atalho de teclado: `Alt` + `Shift` + `S`.

### 📥 Instalação

1. Instale a extensão **Violentmonkey** no navegador.
2. Instale o script pelo link direto no badge acima ou cole o código-fonte manualmente.
3. Acesse `www.youtube.com`.

### 🛠️ Tecnologias

- JavaScript (ES6+)
- API GM (`GM_getValue`, `GM_setValue`, `GM_registerMenuCommand`)
- Injeção dinâmica de CSS
- Cache de DOM e tratamento de navegação SPA
