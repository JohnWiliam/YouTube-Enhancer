## 🇺🇸 English

YouTube Enhancer is a powerful userscript for **Tampermonkey on Microsoft Edge** that improves YouTube performance, Edge compatibility, and usability through a modern settings panel.

### ✨ Main Features

1. **⚡ Smart CPU Tamer (v2.3)**
   - Reduces script activity when the tab is hidden to lower CPU usage, heat, and battery drain.
   - Includes a 30-second grace period and intelligent soft throttling for Edge/Tampermonkey, keeping background media playback and subtitles smooth without UI freezes.

2. **🎨 Grid Layout Control**
   - Choose how many videos appear per row (**3 to 8**).
   - Responsive behavior for smaller screens.

3. **🚫 Shorts Removal**
   - Removes Shorts shelves, menu entries, and Shorts-style listings.

4. **⏰ Floating Clock (Fullscreen)**
   - Displays time overlay during fullscreen playback.
   - Fully customizable: colors, opacity, size, margin, border radius.

### ⚙️ Settings Panel

No code editing required:
1. Open the Tampermonkey script menu.
2. Click **"⚙️ Settings"**.
3. Configure features and clock appearance.

> **Note:** some changes (like CPU mode and language) require **Apply and Reload**.

### 📥 Installation

1. Install **Tampermonkey** in Microsoft Edge.
2. Install the script via direct link (badge above) or paste the source manually.
3. Open `www.youtube.com`.

### 🛠️ Technologies

- JavaScript (ES6+)
- GM API (`GM_getValue`, `GM_setValue`, `GM_registerMenuCommand`)
- Dynamic CSS injection
- Edge/Tampermonkey-focused DOM caching, idle scheduling, and SPA cleanup

## 🇧🇷 Português

O YouTube Enhancer é um userscript poderoso para **Tampermonkey no Microsoft Edge** que melhora compatibilidade com Edge, desempenho e usabilidade do YouTube por meio de um painel moderno de configurações.

### ✨ Funcionalidades Principais

1. **⚡ Smart CPU Tamer (v2.3)**
   - Reduz a atividade de scripts quando a aba está oculta, ajudando a diminuir uso de CPU, aquecimento e consumo de bateria.
   - Inclui período de graça de 30 segundos e ajuste suave de quadros para Edge/Tampermonkey, mantendo reprodução em segundo plano e legendas fluidas sem travar a interface.

2. **🎨 Controle de Layout Grid**
   - Permite escolher quantos vídeos aparecem por linha (**3 a 8**).
   - Comportamento responsivo em telas menores.

3. **🚫 Remoção de Shorts**
   - Remove prateleiras, entradas de menu e listagens do tipo Shorts.

4. **⏰ Relógio Flutuante (Tela Cheia)**
   - Exibe hora sobre o vídeo em tela cheia.
   - Totalmente personalizável: cores, opacidade, tamanho, margem e borda.

### ⚙️ Painel de Configurações

Sem editar código:
1. Abra o menu do Tampermonkey.
2. Clique em **"⚙️ Configurações"**.
3. Ajuste funcionalidades e aparência do relógio.

> **Nota:** algumas alterações (como CPU e idioma) exigem **Aplicar e Recarregar**.

### 📥 Instalação

1. Instale a extensão **Tampermonkey** no Microsoft Edge.
2. Instale o script pelo link direto (badge acima) ou cole o código-fonte manualmente.
3. Acesse `www.youtube.com`.

### 🛠️ Tecnologias

- JavaScript (ES6+)
- GM API (`GM_getValue`, `GM_setValue`, `GM_registerMenuCommand`)
- Injeção dinâmica de CSS
- Cache de DOM, agendamento ocioso e limpeza SPA focados em Edge/Tampermonkey
